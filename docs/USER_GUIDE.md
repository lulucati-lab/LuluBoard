# 使用指南

## 开始创作

首次启动不会创建作品或业务文件夹。点“新建画布”，点击左上名称重命名。返回箭头进入主页。素材库在右上角，已下载的常用素材无需联网。

将素材拖到画布上指定位置；选中自己的文字、图形或组合拖入个人素材库可收藏副本。右键个人素材可删除，需要确认。图片与网页嵌入暂不支持收藏进素材库。

## 查看模式

点左上眼镜按钮进入查看模式，标题与底部工具消失。中间工具栏向上收起，鼠标靠近顶部时展开；悬停不会修改作品。点工具可回到编辑，眼镜按钮或 Alt+R 可切换。

## 保存与恢复

停笔 2 秒、持续编辑每 30 秒及离开编辑器时保存。内容变化时每 5 分钟保留历史，最多 20 份。命令面板可进入历史版本。回收站不会自动清空。

桌面窗口关闭前等待保存完成；保存失败时窗口保留，请检查错误、磁盘空间与目录权限，或导出备份。不要强制结束进程。异常断电后浏览器草稿可辅助恢复，但不能代替定期完整备份。

设置 → 文件存储可选择新的空文件夹。完成复制和逐文件校验后切换，原目录保留。不要让两个独立应用副本同时写入同一个目录。

设置 → 备份与恢复包含全部画布、图片、文件夹、回收站、历史和素材库。单份备份最多 256MB。恢复为新副本；素材按编号合并，已有素材优先。素材恢复失败可单独重试。

## 从当前浏览器版迁入

旧版主页打开设置，下载完整 `.boardbackup`。安装桌面版，设置 → 选择备份恢复，检查数量后确认。确认作品与个人素材完整后再考虑处理旧数据；安装不会自动搬走或删除旧目录。

## 安装、升级与卸载

首发面向 Windows x64。安装目录存程序，用户目录存数据。升级前先导出完整备份，退出应用后运行新版本安装程序。卸载保留创作数据；若要彻底删除，请先备份并自行确认真实保存路径。

测试版尚未进行商业代码签名；只使用作者发布的文件并比对 SHA256。不要为了安装而关闭系统安全防护。

## 网络与限制

核心创作与内置素材在离线环境可用。自定义远程字体、网页嵌入及在线素材网站需要网络；未提供云同步、多人协作或自动更新服务。
